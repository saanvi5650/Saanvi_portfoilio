# Saanvi Portfolio

A one-page scrapbook-inspired personal portfolio built with HTML, CSS and JavaScript.

## Design direction
- lilac / pink / off-white palette
- torn-paper section edges
- taped / polaroid scrapbook details
- subtle lilies and handwritten accents
- professional body typography
- responsive mobile navigation
- reveal-on-scroll animation, cursor glow, gentle tilt and project modal interactions
